# Security policy / Sicherheitshinweise

**Please do not open a public issue for security problems.** Report them privately to **security@opnexus.dev** (German or English) with the affected version, steps to reproduce and the impact you see. Do not include real credentials or firewall data.

I will acknowledge your report as soon as I can, keep you informed about the fix and credit you in the changelog if you wish. This is a one-person project, so please allow some days for a first reply.

**Supported versions:** the latest release only.

---

**Bitte keine öffentlichen Issues für Sicherheitsprobleme.** Meldungen vertraulich an **security@opnexus.dev** (Deutsch oder Englisch), mit betroffener Version, Schritten zur Reproduktion und der Auswirkung. Bitte keine echten Zugangsdaten oder Firewall-Daten mitschicken.

Ich bestätige den Eingang so bald wie möglich, halte dich über die Behebung auf dem Laufenden und nenne dich auf Wunsch im Changelog. Es ist ein Ein-Personen-Projekt — für eine erste Antwort können ein paar Tage vergehen.

**Unterstützte Versionen:** nur das jeweils neueste Release.
